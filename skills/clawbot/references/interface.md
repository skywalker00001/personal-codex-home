# 当前布局与功能约定

以 `feishu_cards.py`、`feishu_history.py`、`feishu_settings.py`、`feishu_bot.py` 和共用 `chat_engine.py` 为准。以下是 2026-10-19 的实现基线；修改时先比较当前源码及用户的新要求。

## 飞书卡片

普通回复的卡片为 schema `2.0`，默认蓝色标题 `Houyi Codex · 飞书`；自定义历史标题用 indigo。正文之后附分组操作区：

```text
正文 / 当前会话 / 结果 / 进度

会话操作
[会话] [当前] [历史]
[新建] [分支] [停止]
[一键解锁全部会话]
解锁会断开已占用的 Codex 连接并中断当前回复，历史保留。

会话设置
[选择模型] [推理强度] [权限]
```

`row()` 用 `column_set` + 相同 weight 的 `column` 放置等宽按钮，间距 8px；不要退回旧 schema 的 action 容器。停止及解锁为 danger 样式；分支带确认。历史上的“五按钮单行/不显示强度”描述早于当前分组布局，不能据此撤掉当前已有控件；新的布局变更以用户本次要求为准。

当前选择的模型、强度、权限使用 primary 高亮。模型按钮每行最多 2 个；强度按钮每行最多 3 个；权限每行 1 个。模型菜单只显示真实模型名称，不把 medium/high 填成模型选项。

会话列表每项提供 `进入 · 标题`，回调绑定真实 thread ID，不能依赖列表更新后会变化的编号。列表有上一页/下一页，菜单口令可刷新旧卡片。

## 标题与“当前”

飞书主题优先取本桥接别名、原线程 name/title、preview，最后才退回 ID 前缀。遇到通用“飞书新会话/新对话”等占位标题，优先用实际 preview。新建草稿显示等待首条消息；首条消息规范空白并截为最多 64 字命名，调用 `thread/name/set`，失败也保留本地别名。卡片主标签最多 42 字，可有省略号，但不能替换成无关标题。

“当前”输出：

```text
当前：真实主题的可读缩略
目录：实际 cwd
状态：可续聊 / 占用 / 等待回复 / 新草稿等
与该状态相符的下一步提示
最近运行模型：实际模型 / 实际强度
```

最近运行模型只在有记录时显示；不要伪造默认值。不要重新加入冗余的“模型（下轮采用）”“推理强度（下轮采用）”“最近运行权限”三行。设置菜单仍需说明下一轮生效。

## 飞书历史

- 从只读 `Catalog.history` 获取历史。新版分页历史走 `thread/turns/list` 并处理 cursor，不能只读 `rollout.jsonl` 或只看 `thread/read.turns`。
- 用户消息为浅蓝 `blue-50`、`👤 你` 标签；Codex 回复为浅灰 `grey-50`、`🤖 Codex` 标签。用户原文用 plain_text，保留角色区分，不能把用户文本中的“Codex：”当成角色标记。
- 最近 3 轮为一页，从提问到回复顺序阅读；不同轮次分隔。缺回复的轮次明确显示暂无保存回复，不造一条回答。
- 超过 700 字显示标明的预览并提供全文按钮；全文按 `split_text(limit=7000)` 的 UTF-8 字节上限分段，提供上一段/下一段和返回历史，不默默按微信的 1800 字限制截掉。
- 一次打开建立固定快照；翻页不因新消息插入而漂移，点击“历史”重新刷新。快照有效约 24 小时，最多保存最近 8 份；跨会话或过期时要求重新打开。
- 规范化换行转义等导出痕迹时保留代码围栏、代码内容和 URL，不给用户展示原始 rollout 事件或工具 JSON。

## 模型、推理强度和权限

模型从 `model/list` 分页获取，使用当前账号/提供商可用集合；推理档位来自所选模型的 `supportedReasoningEfforts`，切模型时清理不支持的旧档位。保存到 `feishu_thread_settings`，新草稿创建成功后迁移到真实 thread ID，分支继承原选择。有效运行记录在 `feishu_effective_settings`。

设置由 `thread/start|resume|fork` 与 `turn/start` 参数下发，不修改全局 config.toml。运行中拒绝修改；旧设置卡片不能修改后来切换的另一会话；旧强度卡片也不能修改另一模型。其他客户端使用同一个原生 thread 时，可能沿用该 thread 最近一次持久化设置。

| 飞书权限值 | approvalPolicy | turn sandboxPolicy |
| --- | --- | --- |
| `read-only` | `never` | `readOnly`，networkAccess=false |
| `workspace-write` | `on-request` | `workspaceWrite`，writableRoots 为 cwd，networkAccess=false |
| `danger-full-access` | `never` | `dangerFullAccess` |

选项必须通过 `configRequirements/read` 过滤；管理员指定专用 allowedPermissionProfiles 时，当前菜单不能擅自覆盖。新建飞书草稿默认完全访问；不允许时明确报限制，不静默降低权限或自动绕过管理配置。手动给现有会话选择完全访问仍有卡片确认。

不要把飞书默认权限推广到微信：当前微信 `thread/start` 仍是 workspace-write/on-request。历史会话不因查看菜单而统一重写权限。

## 按钮、审批与停止

回调值只发送随机 token，服务从持久化 `feishu_actions` 解析命令，不信任客户端提供任意原始命令。token 有效约 24 小时，最多保留 500 项。校验 owner、私聊 chat ID、选中线程及模型；过期时发送“菜单”刷新。

命令执行、文件变更和权限请求提供批准/拒绝按钮；问答由文本 `回答 编号 内容` 路由，多题用 `|` 分隔。Full access 下不应为每个普通请求人为插入审批流程；实际仍服从原生 Codex 的管理员与运行约束。

停止是单击请求，不增加第二次确认。回调入站时记录所选 thread 和任务 started 时间；延迟/重复回调不停止随后启动的任务。旧卡片属于同一会话时可停止点击时的当前任务；属于其他会话时拒绝。空闲时点击不会取消后来才启动的任务。中断期间新发的内容不追加旧 turn，需要在“已中断”后重发。

一键解锁是全 Home 操作，不依赖当前选中的线程；仍须绑定用户/私聊验证。其断连后果及操作审计见维护参考，不能把它当作普通停止的实现。

## 微信交互

当前为本人 iLink 私聊，使用文本口令和手机排版。没有为这套 transport 接入飞书式卡片按钮、外部浏览器控制面板或个人好友选择器。旧 `server.py/index.html` 是独立手机网页原型，不能拿它冒充微信聊天内控件。

| 口令 | 当前功能 |
| --- | --- |
| 会话、搜索 关键词、下一页、上一页 | 最近 8 条会话/搜索结果与稳定列表快照 |
| 切换 2、#2、列表后回复数字 | 切换；只有等列表选择时纯数字才是序号，否则是聊天内容 |
| 当前、历史 | 当前信息；最近 6 条用户/最终回复消息，每条最多显示 1800 字 |
| 新建 名称、分支、归档会话 | 草稿；复制原历史到新线程；查看归档并在续聊前 unarchive |
| 收藏、取消收藏、收藏列表、命名 名称、上一个 | 常用会话、微信本地别名和切回前一会话 |
| 进度、任务、停止 | 任务状态；中断该桥接的当前 Codex turn |
| 批准 编号、拒绝 编号、回答 编号 内容 | 回复原生审批与问答 |
| 手机排版、完整排版、原文 | 移动端格式与最近完整回复，选择跨服务重启保存 |
| 接入状态、语音状态、帮助 | 当前账号/模型接入；最近语音来源；口令提示 |

口令完整匹配；“停止这次训练，先检查日志”是任务正文，“停止”才是桥接中断。用 `说 会话` 将管理口令本身作为正文提交。未选中目标时不自动执行用户问题，选择后需重发。

运行中普通消息通过 `turn/steer` 追加到当前 turn；等待审批/回答、中断中或尚未得到 turn ID 时不强行 steer。切换会话不取消原任务；共用引擎当前每个入口最多同时运行 3 个任务。每条进展带会话名称。

微信默认将表格转短行、简化难读标记并隐藏部分长路径/原始引用；`原文` 可取上条完整文字。代码命令保留，URL 作为文字，长消息按 UTF-8 字节分段、按顺序发送；这不改变桌面端直接提交的指令。

语音：下载并解密绑定用户录音，SILK 解码成 WAV，由本地 CPU 音频模型理解；失败回退微信转写。原音理解和转写来源可查询，回复仍为文字。

发图：仅在用户明确要求发送时使用工作区内图片：

```bash
cd /aigc/avatar/houyi
codex_wechat_bridge/.venv/bin/python codex_wechat_bridge/send_image.py /aigc/avatar/houyi/output/要发送的图片.png
```

PNG/JPEG/GIF/WebP，不超过 10 MiB；固定发给已绑定用户，不支持传任意好友名或 ID。无需重启机器人。接口成功只证明接受请求，手机实际展示需客户端验收。

飞书当前只接入文字/按钮；微信入站图片、文件、视频尚未进入 Codex。不得把出站发图或微信语音支持描述成两端已支持所有媒体附件。
